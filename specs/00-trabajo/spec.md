# Spec — Trabajo sobre las especificaciones

---

## 1. Alcance

Cada cambio se limita a lo que pide el mensaje y a lo que exige la spec de la etapa que ese mensaje nombra.

Si durante el trabajo aparece otro defecto, se informa en la respuesta y queda sin tocar hasta que un pedido lo incluya.

## 2. Revisión previa

Antes de editar se muestra, para cada cambio:

- archivo y lugar
- qué está mal
- el texto que quedaría

El cambio se aplica después del OK.

## 3. Orden

La spec de la etapa define el comportamiento. El código en `src/` se escribe a partir de ella.

Una regla nueva o corregida se escribe primero en la spec y se anota en la bitácora de esa etapa.
